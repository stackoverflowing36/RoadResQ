# RoadResQ — Desktop EOC Control Room Web Application

This directory contains the **desktop-optimized web applications** designed for Emergency Operations Centers (EOC), disaster surveillance commanders, and logistics coordinators.

## Key Features
- **Surveillance & Incident Mapping:** High-resolution map with real-time hazard polygons, BLE mesh node markers, and emergency severity levels.
- **Logistics SITREP Integration:** Live tracking of supply convoys, alternate detour calculations, and automated situational reports.
- **Role-Based Access Control:** EOC Commander, Field Commander, and Logistics Dispatcher authentication flows.
